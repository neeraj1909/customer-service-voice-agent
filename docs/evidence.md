The report records the actual source hashes, revision, dirty flag, Python, Node, platform, case outcomes, HTTP traces and timing. It exits nonzero on an observed failure or a source changing during execution. Temporary reports are local run artifacts, not permanent evidence; rerun to reproduce.

The run passed 18/18 controlled cases: English 6/6, Hindi command forms 6/6, Hinglish command forms 6/6. All 18 language and semantic reviews remain **unreviewed**. The evaluator launches an isolated loopback app and freshly seeded SQLite database for each case and exercises the production browser `Conversation` module against actual HTTP endpoints. It checks independently specified path, response, selected request fields, per-turn visible fragments, appointment version and slot occupancy, other customer's appointment, expected operation and handoff counts. These exact-command checks do not establish natural-language understanding. The unsupported-input case does not test injection in tool results. The suite does not establish concurrency or interruption behavior; consult separate integration evidence for those boundaries.

The first final run recorded 31 command samples, p50 7.49 ms and p95 11.39 ms using Node's monotonic clock from controlled `send(command)` to completion, including loopback HTTP when called, excluding server startup. Each case uses a fresh server, with sequential turns; cold versus warm samples are not classified. This is controlled-text timing on the recorded machine, not voice, model, microphone, network, or production latency. No latency target or general performance claim follows.

`uv run pytest -q tests/evaluation` passed 4 tests. An altered expected appointment slot produced CLI exit 1; an altered required visible human-connection fragment also produced CLI exit 1. A separate unit probe verifies an actual fabricated English human-connection phrase and incorrect tool arguments are flagged; it is not an exhaustive multilingual hallucination detector. These probes test the evaluator's sensitivity, not production safety in general. No external model provider, real customer, real human transfer, or live voice model was used.
