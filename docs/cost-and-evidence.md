# Cost and evidence register

Updated 2026-11-08. This local learning project authorizes no paid APIs, subscriptions, billable services, real customer data or production deployment. Verify changing dependencies, sources, licenses and resource use before each new setup; no provider path should be inferred from this register.

| Path | Prerequisites and cost boundary | Evidence and limitations |
| --- | --- | --- |
| Controlled text demo | Python, uv, Node and locally cached `uv.lock` distributions; loopback-only server and seeded SQLite data. No model/provider integration. A fresh package download may require network but must not create paid resources. | Actual UI/HTTP/SQLite browser journeys and controlled evaluation ran. The Python socket guard test is not operating-system network isolation. |
| Local speech recognition | Disabled unless `LOCAL_AUDIO_ENABLED=1` and a trusted local Whisper CLI and model are explicitly configured. No hosted fallback. | Existing `ggml-tiny.bin` weighs about 75 MiB; SHA-256 `be07e048e1e599ad46341c8d2a135645097a538221678b7acdd1b1919c6e1b21` matched published whisper.cpp metadata. No model was downloaded for this work. Prior local binary provenance remains unverified. Synthetic Hindi and one browser English input failed; see [evidence](evidence.md). A filename alone cannot verify model language support. |
| Local speech synthesis | Opt-in audio and installed `libespeak-ng.so.1`; no hosted speech service. | Hosted provider / live model | Disabled and not configured. Existing access, incremental charges, terms and data handling are unverified. | Do not enable without verification that the exact route incurs no additional charge and is authorized. |
| Local container | Docker CLI was present during inspection; no container was needed or validated. | Use the documented local process; no image or hosted infrastructure was deployed. |

A configured local executable is trusted code and is **not OS-sandboxed by the audio adapter**. The adapter launches it without a shell, but a malicious or misconfigured executable could make network requests or access local data. Only configure trusted binaries/models; validate licenses, hashes and runtime network behavior when this boundary matters. The separate Pipecat namespace isolation does not apply automatically to the app or ASR subprocess.

The browser runner's optional synthetic audio mode uses local `ffmpeg`, eSpeak NG, Whisper and a compatible model; it creates and cleans up temporary data. Its success after manual correction does not prove ASR accuracy. The normal app accepts bounded mono PCM WAV directly and does not call ffmpeg. Prerecorded audio, simulated media, actual microphone use, local inference and a real service are distinct evidence categories; report each separately. No actual microphone, human transfer or production traffic was exercised.
